# ScrollNotebook

미리보기: `/test/notebook` (테스트 목록 `/test`에도 등록).

736 × 920 비율의 3링 노트입니다. 표지·종이 더미·정지 종이·회전 종이·금속 링을 별도 레이어로 구성합니다. 이전 원본 `public/images/notebook/notebook.png`는 참고용으로만 남기며 화면에서는 사용하지 않습니다. 위쪽에는 직전 페이지가 표시됩니다.

- `NotebookBinding.tsx`의 링 3개는 Y/Z 평면의 작은 금속 면들로 이어진 독립적인 3D 루프입니다. 종이와 같은 3D 공간에서 깊이 순서로 앞뒤가 가려집니다.
- 종이에는 CSS 마스크로 실제 구멍 3개를 뚫습니다. 링과 구멍의 가로 좌표는 `RING_POSITIONS`를 공유합니다.
- 외부 페이지 넘김 라이브러리를 사용하지 않습니다. `paper-fold.ts`는 펼쳐진 면 → 180도 U자 곡면 → 뒤집힌 면 하나로 종이를 연결합니다. 전체 종이 회전과 별도 몸체 접힘을 더하지 않습니다.
- 상하 진행률은 U자 경계를 자유로운 끝에서 제본부 쪽으로 이동시킵니다. 좌우 위치는 경계의 기울기만 정하며, 구멍에 도달하기 전에는 수평으로 정렬합니다. 처음 잡은 가로 위치나 누적 접힘 값은 사용하지 않습니다.
- U자는 첫 이동부터 180도를 유지합니다. 시작 시 반경만 작게 만들어 종이가 튀어나오지 않게 하고, 이후에는 링보다 조금 넓은 반경으로 말려 올라갑니다. 곡면은 16개 작은 면으로 이어지며, 끝까지 넘어가면 곡면 자체가 종이 밖으로 빠져나가 별도 펴기 동작 없이 평평해집니다.
- `notebook-geometry.ts`의 링 원주 좌표로 세 구멍을 연결합니다. U자가 구멍에 도달하기 전에는 구멍이 원래 위치에 남고, 도달한 뒤에는 링을 따라 이동합니다. 종이 전체를 링 위 별도 레이어로 분리하지 않습니다.
- 포인터를 누르는 것만으로는 변형하지 않습니다. 위아래로 8px 이상 이동해야 말림이 시작됩니다. 수평으로만 드래그했다가 놓으면 탭 넘김을 실행하지 않습니다.
- 뒷면에는 앞면 인쇄가 옅은 반전상으로 비칩니다. 정착한 위쪽 페이지에도 같은 표현을 유지해 완료 시 내용 방향이 바뀌지 않습니다.

```tsx
import ScrollNotebook, { type NotebookPage } from "@/components/notebook/ScrollNotebook";

const pages: NotebookPage[] = [{
  id: "first",
  elements: [
    {
      id: "message", type: "text", text: "우리의 이야기\n함께 시작해요",
      x: 8, y: 10, width: 80, fontFamily: "'My Handwriting', cursive",
      fontSize: 32, color: "#534c40", rotation: -3,
    },
    {
      id: "photo-1", type: "image", src: "/photos/first.jpg", alt: "첫 여행",
      x: 10, y: 42, width: 44, height: 48, rotation: -5, zIndex: 1,
    },
    {
      id: "photo-2", type: "image", src: "/photos/second.jpg", alt: "함께한 바다",
      x: 48, y: 48, width: 43, height: 44, rotation: 7, zIndex: 2,
      objectFit: "contain", borderRadius: 4,
    },
  ],
}];

<ScrollNotebook pages={pages} label="우리의 여행 기록" />
```

- 페이지는 최대 10장입니다. 초과 데이터는 처음 10장만 사용하며 빈 배열이면 표시하지 않습니다.
- `elements`의 개수 제한은 없습니다. 위치와 너비/높이는 페이지 내부 쓰기 영역의 백분율입니다. 회전은 도 단위, `zIndex`로 겹침 순서를 설정합니다.
- `fontSize`는 원본 너비 736px 기준 픽셀 크기입니다. 화면 크기에 따라 글씨와 배치가 함께 축소됩니다. `fontWeight`, `lineHeight`, `textAlign`도 설정할 수 있습니다.
- 원하는 웹폰트를 프로젝트에서 먼저 불러온 뒤 `fontFamily`에 전달하세요. 예제의 폰트명은 로컬 폰트가 없으면 대체 글꼴로 표시됩니다.
- 이미지는 `src`와 `alt`를 전달합니다. `height` 생략 시 이미지 원본 비율을 사용합니다. 같은 페이지에 여러 이미지를 자유롭게 배치할 수 있습니다.
- 영역 안에서 마우스나 터치로 드래그하면 상하 이동으로 넘기는 정도를 조절하고, 좌우 이동으로 접히는 방향만 즉시 바꿉니다. 수평으로만 이동하면 진행률은 그대로 유지됩니다. 자동 넘김도 같은 진행률 계산을 사용해 마지막 위치까지 이어집니다. 놓을 때 절반 이상 진행했거나 빠르게 넘긴 경우 완료하고, 짧게 당기거나 반대로 튕기면 복귀합니다.
- 아래쪽 페이지를 탭하면 다음 장, 위쪽을 탭하면 이전 장을 600ms 동안 넘깁니다. 버튼·방향키·휠도 같은 속도를 사용합니다.
- 스크롤 제스처 하나당 한 장씩 넘깁니다. 트랙패드 관성 스크롤은 연속 넘김을 방지합니다. 터치 드래그, 위아래 방향키, PageUp/PageDown, 이전/다음 버튼도 지원합니다.
- 처음/마지막 페이지 밖으로 스크롤하면 바깥 문서 스크롤을 허용합니다. `prefers-reduced-motion`에서는 자동 전환과 드래그 후 정착 애니메이션을 생략합니다. 드래그 중에는 손의 위치를 그대로 따릅니다.
- 페이지 데이터의 id는 고유하게 유지하세요. 다른 노트로 교체할 때는 React `key`를 변경하면 첫 페이지부터 시작합니다.
